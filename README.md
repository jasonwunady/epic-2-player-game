# EPIC 2 Player Jump Game

A competitive 2-player platformer game built with Phaser 3.

## Features
- 20,000 pixel tall massive level
- 2-player split-screen gameplay
- Attack system with projectiles
- Bounce pads, spike traps, and lava obstacles
- Cracking platforms
- Health system
- Confetti celebration effects

## Controls

**Player 1 (Red Orc)**
- W: Jump
- A: Move Left
- D: Move Right
- S: Attack (throw axe)

**Player 2 (Teal Soldier)**
- Up Arrow: Jump
- Left Arrow: Move Left
- Right Arrow: Move Right
- Down Arrow: Attack (shoot arrow)

## How to Run

Simply run:

```bash
npm start
```

Then open your browser to: `http://localhost:8000`

## Files
- `index.html` - Main HTML file
- `game.js` - Phaser 3 game logic
- `styles.css` - UI styling
- `server.js` - Simple Node.js web server
